# Interactive CS and AI Simulations

Browser simulations that make algorithms and machine learning visible. Every demo starts with a system that knows nothing, lets the learner break or train it, and shows the numbers behind each decision.

**Live site:** https://cynthialmcginnis.github.io/CS-simulations/

| Demo | Concept |
|---|---|
| [Route Lab](route-lab/) | Graphs, Dijkstra's algorithm, decisions from noisy data |
| [Reinforcement Learning](reinforcement-learning/) | Q-learning, self-play, multi-armed bandits |
| [How an LLM Generates Text](how-llm-generates-text/) | Next-token prediction with a real GPT-2 model |
| [Opening the Black Box](llm-matrix-visualization/) | The matrix math inside a language model |
| [3D Word Embedding Space](word-embedding-3d/) | Embeddings as vectors |
| [Train a Model](train-a-model/) | Training and testing a neural network classifier |
| [Computer Vision](computer-vision/) | Pixels, RGB values, edge detection |

Design walkthroughs: [Route Lab](pdfs/Route_Lab_Walkthrough.pdf) · [Reinforcement Learning](pdfs/Reinforcement_Learning_Walkthrough.pdf)

Each demo is a single HTML file with no build step. Built by Cynthia L. McGinnis, Associate Professor of Mathematics and Computer Science, UMGC Asia.
